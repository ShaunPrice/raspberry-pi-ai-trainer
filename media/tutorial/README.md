# Pi Trainer walkthrough

The illustrated user guide is available in the [guide release](https://github.com/ShaunPrice/raspberry-pi-ai-trainer/releases/tag/tutorial-v1). [Watch the narrated walkthrough on YouTube](https://youtu.be/O7UQfUIOpUI). Video, caption and forum media downloads are retained locally and are not hosted as GitHub release assets.

- `Pi-Trainer-User-Guide.pdf`: illustrated instructions for all four interfaces.
- `Pi-Trainer-User-Guide.docx`: editable version of the guide.

The video contains actual web-workbench captures recorded during project creation, dataset import, training, packaging and workflow preparation. Idle sections are edited or held. The native overview is an actual application-window screenshot. The training and packaging jobs completed during recording; compiler, image, device and LLM screens demonstrate configuration, not execution. The package uses a previously verified synthetic HEF rather than the colour model trained on screen.

Narration uses ElevenLabs Ellen — Serious, Direct and Confident, generated with Eleven v3 through the existing signed-in account. Light instrumental music was generated locally using ACE-Step, with no vocals, and mixed quietly below speech. The closing sequence fades to black and silence.

The title photograph is credited to Raspberry Pi Ltd, from the [official AI HAT+ product page](https://www.raspberrypi.com/products/ai-hat/) ([photo](https://assets.raspberrypi.com/static/2eafb587744a455d494acf1b3127a3e1/1a2fa/camera-stacked.jpg)). It is an official product photo, not a photograph of the test devices. The third-party photograph retains its original copyright and is not covered by this repository's MIT license.

The pronunciation script, [normalized caption text](caption-script.json), [caption builder](build_captions.py) and chapter/capture manifest are versioned here. The September 10 revision replaces the original Karen narration with ElevenLabs; the recording, music and guides are retained. Raw recordings, intermediate audio, document render images and final binaries stay out of Git history. See [the text guide](../../docs/user-guide.md) for searchable instructions.
